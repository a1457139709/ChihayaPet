# Windows 11 x64 实机自测

Issue #62 的 Windows 实机运行及 Issue #63 的视觉 UI 验收交给用户。开发端只验证代码、ZIP、完整运行时、正式资源和路径契约；本清单没有预填实机通过结果。

1. 将 `ChihayaPet-Windows-x64.zip` 完整解压到可写目录，双击 ChihayaPet.exe。无需 Node/npm；托盘出现叶子图标，人物透明，任务栏不驻留人物窗口。首次启动前确认解压目录已有 Data/Music/，resources/BundledBGM/ 中有 43 首 WAV 和 catalog.json；首次启动后确认曲库显示 43 首音乐（已有用户曲库时保留同名文件及已移除曲目）。打开解压目录中的 FILES.txt，确认发行文件和实际 Data 路径。
2. 点击人物打开聊天，关闭聊天后人物仍在。透明角落点击应落到后方窗口；有像素的人物可以点击。拖动超过 4 点只移动，不打开聊天。穿透开启后鼠标操作落到后方，托盘菜单可关闭穿透；重启后穿透关闭。
3. 切换全部造型、全景／近景、多个编号、自动表情和 240–480 点大小。确认无上一张图残留，气泡跟随当前嘴部／发丝位置。关闭动效及 Windows 减少动画时停止身体和逐字动作。
4. 在 100%、150%、200% 显示缩放和多显示器之间拖动。靠近屏幕边缘说一句，气泡换侧并保持可见。拔掉人物所在屏幕，确认人物回到可见工作区。检查虚拟桌面切换及全屏应用；Windows 使用当前桌面的系统窗口规则。
5. 打开中文输入法，Enter 只确认候选，Escape 不误关窗口。确认后 Enter 发送，Shift+Enter 换行；可以复制粘贴和编辑多行文字。
6. 填 HTTPS 服务、模型和密钥，测试草稿不保存。保存后重启检查；切换地址只载入该地址的密钥。查看 Data/config.json 三字段（密钥为明文，不要发送给他人）。测试连接和聊天只能有一个请求；取消、修改测试草稿、保存配置／提示词、清空会话后无迟到回复。分别检查流式和 JSON 服务。
7. 聊天逐字显示，关闭后回复摘录最多四行，“查看全文”定位对应回复。悬停留住气泡，离开约 12 秒收起；手动关闭后不重复出现。聊天、设置、草稿、请求、已有气泡、隐藏和穿透期间不说闲话，恢复后重新计时。
8. 导入 WAV、AIFF/AIF、MP3、M4A/AAC，逐首检查播放、暂停、切歌、音量、单曲／列表循环、启动播放。关闭聊天／设置仍播放；隐藏、锁屏和真实睡眠暂停，恢复尊重手动暂停。移除曲库项不改变原文件；重启后不重新加入已移除的随包曲目。长时间驻留后反复开关面板，检查 CPU、内存和缓存增长。
9. 退出后将整个目录搬到另一位置，再运行，确认所有服务、偏好、原名音乐和文件名排序保留；文件说明更新绝对路径。检查应用控制的数据都在该目录的 Data/。只读目录应清楚提示移动整个文件夹，不改用 AppData。
10. 升级时保留 Data/ 并替换全部发行文件。检查 FILES.txt 中的删除程序和删除数据方法。记录 Windows 版本、屏幕缩放、实际失败步骤和截图；不要在报告中附真实密钥。

每项由实际操作者记录日期、结果和异常。开发端不会将未经运行的 Windows 条目标为通过。

## #73 菜单响应回归

实现：焦点读取改为预加载的 Koffi/Win32 调用，不启动 PowerShell；人物首次显示后预加载 Windows 菜单，关闭时隐藏并复用。新一轮打开重置子菜单及滑块焦点，刷新状态。用户切到其他应用时不主动抢回焦点。

自动验证：

```sh
node --import tsx --test tests/desktop.test.ts tests/windows-focus.test.ts
node scripts/check-menu-reuse.mjs
npm run build
node scripts/package-electron.mjs win
```

Mac 上的窗口边界测试、真实 Electron 菜单渲染测试、Windows 包结构校验不能替代 Windows 实机验收。发行前在同一台 Windows 11 x64 机器，用修改前后 ZIP 完整解压后的 EXE 对比：

- 记录系统、CPU、版本与是否刚启动。分别记录首次打开，以及预加载完成后的 30 次人物右键、30 次托盘右键；报告中位数、P95、最大值。目标为预加载完成后大多数打开在 100 ms 内，不能只计函数耗时，应覆盖输入到首个可见菜单画面。
- 聊天和设置均关闭时测试（确保覆盖焦点记录路径）；另外测试面板已打开的情况。
- 用进程跟踪确认打开/关闭菜单均不产生 PowerShell 子进程。
- 在记事本输入后打开菜单，用 Escape 关闭后检查焦点；点击另一个应用关闭菜单，不应抢回原窗口。
- 打开大小子菜单，连续拖动滑块，然后关闭重开：应返回根菜单，并显示最新高度及播放状态。
- 加载过程中重复右键、托盘双击打开聊天，不应出现空白菜单或迟到的菜单。
- 多屏边缘、缩放、短工作区下检查位置和高度；退出后隐藏菜单窗口必须销毁。
- 同条件记录预加载前后常驻内存和空闲 CPU；隐藏菜单不接收持续状态广播。

本次 Mac 自动验证通过，Windows 点击到可见的延迟和焦点实机行为仍待验证；未据此宣称已达到 100 ms 或关闭 #73。

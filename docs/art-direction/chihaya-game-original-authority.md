# 千早母图：游戏原图优先

2026-09-28 用户明确要求："你绘制的图片头发是暗色的，千早的头发是银色，偏亮色。所有母图以游戏原图为主，特别是头发和面部部分。"

这项要求适用于所有服装、朝向、姿态和衍生表情。游戏原件是发色、发型和脸部身份的依据。2026-09-30 起以[原尺寸喝茶与原脸计划](../plans/2026-09-30-native-tea-and-original-faces.md)为当前制作范围；旧生成物已移出项目，历史冻结要求由本次清理授权更新。

- 头发为明亮银色/银白色，整体受光基调偏亮。阴影只用于交叠和体积，沿发束轻薄、连续；不能用大片中深灰带把侧发、内部发束或卷发压成暗灰发色，也不能仅头顶高光亮、主体仍暗。
- 发型结构、分缝、刘海、发束走向、细线粗细和阴影形态对照原生游戏图。此前指定 `assets/chihaya_character/chi_a_@.png` 为头发标准；冬装同向身体层 `chi_a@.png` 可辅助对照衣着与造型。身体层透明脸孔是分层结构，不应生成空脸。
- 脸型、五官位置、眼睛形状/比例、虹膜颜色、表情神态以对应朝向的游戏脸部层为主。本次冬装阅读使用原生 `assets/chihaya_character/chi00a@.png`。不以旧AI重绘脸型作身份权威，不将其圆钝、柔化或夸大眼形继续继承。
- 原服装优先使用其对应游戏身体/脸部；新服装也必须继承同角色的游戏发色/面部。已确认姿态/服装/道具图只承担相应构图与设计约束。
- 检查必须实际对照游戏原图、原生头部、头顶/刘海/侧发/卷发细节及浅深底；整体提亮、分辨率更大、锐化或数值PASS都不能自动证明改善。
- 全景与近景按各自游戏原画布制作，人物尺度及原脸像素保持原生。喝茶只局部制作手臂、手和茶具，区域外保留原始 RGBA；固定母图后直接合成对应游戏原表情，不逐表情重绘整个人物。
- 确需图像生成时使用内置 imagegen 逐张制作、实际查看与记录；游戏原脸直接复用。AI 绘制与像素核对分别验收，不改原生游戏文件，单张审核后再继续。

# 统一人物气泡与聊天互斥

聊天打开时不再显示人物回复气泡，收起后显示最新未关闭／过期的完整回复摘录。闲话与回复共用 IdleBubbleView、IdleBubbleLayout 和唯一 NSPanel，以及逐字播放、嘴部定位、12 秒收起及悬停计时。旧大矩形回复视图不再由运行时窗口调用。

回复摘录最多 60 个完整 Unicode 字符（含省略号），以实际 CoreText 排版限制四行；有省略或服务截断时提供“查看全文”，返回聊天并定位对应轮次。相同文字的新回复按轮次 ID 区分。请求中收起等待完成，失败／取消不弹出旧回复；隐藏、休眠和清空阻止意外弹出与旧回调复活。

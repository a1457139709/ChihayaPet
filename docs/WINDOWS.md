# 妃宫千早桌宠 · Windows 11

Windows 版使用 Electron，复用 macOS 版的七套分层立绘和角色资源。适用 Windows 11 **x64（Intel / AMD）**；当前包不包含 ARM64 原生运行时。

## 解压与启动

1. 将 `ChihayaPet-1.0.0-win11-x64.zip` 复制到 Windows，右键选择“全部解压”。
2. 打开解压后的 `ChihayaPet-win32-x64` 文件夹，双击 `ChihayaPet.exe`。
3. 请保留整个文件夹里的 DLL、`resources` 和 `locales`；不能只复制 EXE，也不要直接从压缩包内部运行。
4. 首次启动人物显示在主屏右下方。单击人物打开聊天；按住拖动；右键人物或系统托盘叶子图标打开菜单。托盘图标可能位于任务栏的隐藏图标区域。
5. 关闭聊天窗口只收起面板；完全退出请使用托盘中的“退出千早桌宠”。再次启动同一应用会打开已有实例的聊天窗口。

不需要安装 Node.js、Python、.NET 或开发工具。此个人测试包未进行 Windows 代码签名；Windows 可能显示“未知发布者”。请核对随附 SHA256 后，根据自己确认的来源决定是否运行。

## 桌宠和对白

- 七套服装、全景／近景、自动／日常／认真／微笑／惊讶表情，默认 256 DIP，支持 240–480 DIP。
- 支持眨眼、呼吸、轻摆和对白嘴型。关闭“人物动效”或启用系统减少动态效果后显示静态人物／完整对白。
- 支持置顶、隐藏、位置记忆和鼠标穿透。开启穿透后，从**托盘菜单取消“鼠标穿透”**即可恢复操作；“恢复人物位置”用于找回移出屏幕的人物。
- 设置窗口和托盘都可修改偏好。显示器移除或工作区变化时会将人物移回可用区域。
- 聊天面板收起后显示最新完成回复的摘录气泡，最多 60 个字符；“查看全文”返回聊天。
- 主动闲话默认 3–7 分钟一次，也可选择经常 1–3 分钟或安静 10–15 分钟；最近八句不重复。聊天／设置打开、存在草稿、请求进行中、人物隐藏、穿透或系统休眠时暂缓。
- 气泡文字显示完后约 12 秒收起，悬停保留；点击正文可补全当前文字。

## 云端聊天

在“设置”填写 HTTPS 服务基础地址、模型名及 API Key，点击“保存服务”。例如基础地址 `https://example.com/v1`，程序请求 `https://example.com/v1/chat/completions`。不会自动添加 `/v1`；不要填写完整的 `/chat/completions` 路径。

服务需兼容文本 Chat Completions。支持 SSE 流式响应，也兼容直接返回 JSON 的服务。Enter 发送，Shift+Enter 换行；输入法选词确认不会发送。请求可取消，失败／取消的未完成片段可重试。测试连接使用当前草稿，与聊天共享一个请求名额，可能产生服务费用。单次请求总等待上限 60 秒，不自动重试、不跟随重定向。

API Key 留空且未编辑时，保留该基础地址已保存的密钥；主动编辑后清空再保存会删除该地址的密钥。不同地址分别保存密钥。角色提示词可单独编辑保存；保存服务或角色设定会取消当前请求并清空会话。

聊天只存在当前进程内存中，退出或清空后不保留。上下文最多 10 个完整轮次／12,000 个字符，界面最多 50 轮／100,000 个字符；输入最多 2,000 个字符，回复最多 20,000 个字符。未完成回复不进入后续上下文。

## 音乐

在“音乐”页导入 WAV、MP3、M4A、AAC、OGG 或 FLAC，可播放／暂停、上一首／下一首、调节音量、单曲或列表循环。初始曲库为空，默认音量 20%；默认在下次启动播放上次曲目，可关闭“启动时播放背景音乐”。

导入会复制文件；“从曲库移除”只更新索引，保留原文件和已导入副本。隐藏人物、锁屏和休眠暂时暂停，恢复时保留之前的播放／手动暂停选择。关闭面板不停止音乐。AIFF 不在 Windows 导入白名单中，请先转换为 WAV；某些 M4A/AAC 的具体编码是否可播放取决于媒体支持，失败时可转换为 WAV/MP3。

## 数据位置和备份

数据保存在 `%APPDATA%\ChihayaPet\`，与解压位置无关：

- `config.json`：服务地址、模型和按地址索引的**明文密钥**。
- `preferences.json`：角色设定、人物和音乐偏好。
- `Music\library.json` 和 `Music\`：曲库索引及导入副本。

聊天不会写入这些文件。程序不会自动读取 Mac／项目根目录的 `config.json`、`persona.md` 或私人曲库，发行包也不包含这些文件。移动整个解压目录不会丢失数据；删除程序目录不删除用户数据。备份或清理数据前请先从托盘退出。

配置损坏时程序停止启动并提示位置，保留原文件，不会悄悄重置。可先备份数据目录，再修复 JSON 或将损坏文件改名后重新启动。

## 从源码构建

开发依赖 Node.js 22.12+ 和 npm。Mac、Linux 或 Windows 均可执行：

```sh
cd windows
npm ci --ignore-scripts
npm test
npm run check
npm run package:win
npm run verify:win
```

首次打包需要网络，从 Electron 官方发行地址下载固定版本的 Windows x64 运行时并校验 SHA256。构建工具只处理文件，不启动 Windows 程序，不依赖 Wine、虚拟机或 Xcode。产物位于 `windows/dist/`：ZIP、同名 `.sha256`、解压目录及 `build-report.json`。

打包只复制源码、经过哈希校验的运行立绘和素材说明；不会复制原图备份、本地配置或曲库。运行包不需要任何 npm 依赖。当前运行时固定为 Electron 44.4.1；可在 `windows/package.json` 的 `buildConfig` 中查看。

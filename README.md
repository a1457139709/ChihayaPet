# 妃宫千早桌宠

**[访问展示页 →](https://a1457139709.github.io/ChihayaPet/)** · 看看桌面日常、对话示例与衣橱。

让千早在桌面一角，陪你聊几句、听听音乐。

这是使用《少女爱上姐姐2》人物制作的非官方同人桌宠，支持 **macOS 26 及以上（Apple Silicon）** 和 **Windows 11（x64）**。

## 可以做什么

- **桌面陪伴**：拖动人物摆放位置，调整大小、置顶或开启鼠标穿透。
- **换装与表情**：切换服装、表情，以及全景或近景显示。
- **聊天与问候**：接入自己的模型服务与千早聊天，也可以开启偶尔的主动闲话。
- **背景音乐**：播放随包音乐或导入自己的曲目，支持音量调整、切歌和循环播放。
- **自定义角色设定**：在设置里调整说话方式，也可以恢复默认设定。

## 下载与安装

前往 [Releases 页面](https://github.com/a1457139709/ChihayaPet/releases) 下载对应系统的发行包。使用发行包无需安装 Node.js 或其他开发工具。

| 系统 | 下载文件 | 安装方式 |
| --- | --- | --- |
| macOS | `ChihayaPet-macOS-arm64.dmg` | 打开后将 `ChihayaPet.app` 拖入“应用程序”，再启动应用。 |
| Windows | `ChihayaPet-Windows-x64.zip` | 完整解压到可写文件夹，双击其中的 `ChihayaPet.exe`。 |

macOS 版本尚未完成 Apple 公证，首次打开可能受到系统安全提示拦截。Windows 版需要保留整个解压文件夹，不能只复制其中的 EXE；换位置时请一起移动。

## 开始使用

**点击人物打开聊天，拖动人物调整位置。** 右键人物，或通过 macOS 菜单栏／Windows 托盘菜单，可以打开设置、换装、控制音乐或退出应用。

开启鼠标穿透后，点击会落到人物下方的窗口。需要重新操作时，从菜单栏或托盘关闭穿透即可；下次启动时穿透默认关闭。

### 配置聊天

1. 打开设置中的“模型服务”。
2. 填写兼容 Chat Completions 的 **HTTPS API 基础地址、模型名称和 API Key**。基础地址按服务商说明填写，例如 `https://example.com/v1`，无需再附加 `/chat/completions`。
3. 点击“测试连接”，成功后点击“保存服务”。测试不会自动保存设置，也可能产生一次请求费用。
4. 点击人物开始聊天。`Enter` 发送，`Shift + Enter` 换行。

聊天需要自行准备模型服务，费用取决于所选服务。不配置聊天也可以使用换装和音乐功能。关闭聊天窗口后，人物和音乐仍会继续陪伴。

聊天记录只在本次运行中保留，退出应用后不会保存。保存模型服务或角色设定会清空当前对话。消息会发送给你配置的服务，数据保留政策由服务方决定；API Key 以明文保存在本机，请妥善保管数据文件。

### 音乐与主动问候

发行包附带 43 首背景音乐，首次启动会导入曲库。也可以在设置中导入自己的 WAV、AIFF/AIF、MP3、M4A/AAC 音频，并选择单曲或列表循环。

从曲库移除的音乐会放入 `Music/已移除/`，移回后重启应用即可恢复。隐藏人物或电脑睡眠时，音乐会自动暂停。

主动闲话可以在菜单里开关，并调整间隔；聊天或设置时会暂时避让。希望安静陪伴时，关闭闲话即可。

## 数据、备份与升级

| 系统 | 数据位置 |
| --- | --- |
| macOS | `~/Library/Application Support/ChihayaPet/` |
| Windows | `ChihayaPet.exe` 同级的 `Data/` 文件夹 |

这里保存模型配置、密钥、自定义角色设定和音乐。升级前建议备份整个数据文件夹；Windows 更换程序文件夹时，将原来的 `Data/` 一起保留。音乐目录中的隐藏标记文件也应保留，避免升级后重新加入已移除的随包音乐。

macOS 的窗口、闲话和音乐偏好另外保存在系统偏好中。详细文件用途及删除方式见随程序提供的 `FILES.txt`。

随包原始音乐约 1.24 GB，程序和首次导入后的曲库各保留一份，请预留磁盘空间。分享数据文件或提交问题截图前，请移除 API Key 等私人信息。
